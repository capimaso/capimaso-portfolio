# Sons do Windows 7

Adicione aqui somente os arquivos reais, com origem/licença verificadas:

| Arquivo | Evento |
| --- | --- |
| logon.wav | Entrada pelo botão/Enter da tela de boas-vindas |
| startup.wav | Primeiro carregamento do desktop após entrar |
| navigation.wav | Voltar/avançar no Explorer |
| minimize.wav | Minimizar janela, tarefa ativa ou mostrar desktop |
| error.wav | Falhas do Explorer, visualizador, downloads ou busca |

Os WAV ainda não foram fornecidos. Não foram sintetizados ou substituídos.
Ausência significa silêncio, sem requisições de arquivos inexistentes. A página
detecta os arquivos no servidor; reinicie o servidor de desenvolvimento ou faça
novo build/deploy após adicioná-los. Falhas de decodificação/autoplay também
mantêm a interface funcionando, sem alertas. Reprodução só é habilitada após
a interação de entrada; volume 40%. Sair do Win7 libera os elementos de áudio.
