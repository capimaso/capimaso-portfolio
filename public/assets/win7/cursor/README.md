# Cursor ocupado do Windows 7

`Busy.ani` é o asset original fornecido pelo proprietário. `Busy.cur` é o
primeiro chunk `icon` desse RIFF ACON, extraído integralmente (4.286 bytes),
incluindo o cabeçalho CUR e hotspot original (16, 16). Nenhum pixel foi alterado.

A cobertura preta de entrada usa esse frame estático: navegadores não oferecem
suporte interoperável a cursores ANI. O caminho público correto é `cursor/`,
no singular. O cursor funciona sem depender do tema instalado no computador.
